# Лад

Личный песенник с аккордами, визуальными табулатурами и вокальным тренажёром. React 19, TypeScript, Vite; данные хранятся в браузере, сервер не требуется.

## Обновление интерфейса и интерактивные лики

Упрощены рабочие экраны, добавлены раскрываемые настройки и проверка гитары по шагам. [Что изменилось и как подключить гитару](docs/WORKSPACE-AND-GUITAR-INPUT.md) · [Результаты проверки](docs/VERIFICATION-WORKSPACE.md).

## Запуск

Используйте Node.js 22.12+.

```bash
npm ci
npm run dev
```

Откройте **http://localhost:5174**. На Windows, если PowerShell блокирует npm, используйте `npm.cmd` вместо `npm`.

## Сольфеджио

Самостоятельная вкладка практики: 14 видов генерируемых упражнений, диктанты, интерактивный кварто-квинтовый круг, интонация и локальный прогресс. Для звука используется рояль из табулатур. Отдельный учебник «Теория музыки» (11 тем) находится в боковом меню. Песни загружать не нужно. [Подробная инструкция и структура модуля](docs/SOLFEGE.md).

## Гитарная практика

Меню → Гриф и гитара → Гитарная практика: пять боксов пентатоники, 20 ликов с анимированными движениями, 20 прогрессий и блюзовый шаблон. Звуки и каталог локальные, API не используется. В сольфеджио интервалы и трезвучия теперь строятся на клавиатуре. [Инструкция, структура и ограничения](docs/GUITAR-PRACTICE.md).

## Вокальный тренажёр

**Обновление 22.10.2026:** отдельная вкладка в главном меню, исправленные загрузки и синхронизация MIDI/аудио, новый анализ акапеллы, октавный сдвиг нот, масштаб 1–800% и готовый шаблон припева «Осени». [Как запустить и что изменилось](docs/VOCAL-UPDATE.md) · [Как использовать шаблон](docs/OSEN-CHORUS.md).

В разделе «Вокальный тренажёр» раскройте «Учебные примеры и шаблоны песен» и откройте «Плавная фраза», «Ритм и восьмые» или «Длинные ноты». Это три самостоятельные учебные мелодии с редактируемой вокальной линией и звучащей фортепианной партией.

У любой песни есть вкладка «Вокальный тренажёр»: импорт MIDI, распознавание чистой акапеллы, преобразование визуальной табулатуры, ручной Piano Roll и тренировка с микрофоном. Есть светлая/тёмная тема, независимые скорость и тональность, минусовка, петля и отсчёт.

Для микрофона нужен localhost или HTTPS. Включите его кнопкой после нажатия «Тренироваться» и используйте наушники. Аудиофайлы после перезагрузки страницы нужно выбрать снова; ноты и настройки сохраняются. Перед переносом приложения на другой адрес экспортируйте библиотеку: localStorage привязан к адресу сайта.

Три согласованные песни — «Выхода нет», «Районы-кварталы», «Отпускай» — пока представлены **заготовками со ссылками на разборы**, без оригинальных нот и фонограмм. Учебные мелодии выше не являются их транскрипциями.

## Проверки

```bash
npm test
npm run build
npx playwright install chromium
npm run test:e2e -- e2e/vocal.e2e.ts e2e/vocalRecovery.e2e.ts
```

Production-сборка находится в `dist/`; для локального просмотра выполните `npm run preview`. Не открывайте `index.html` через `file://`: приложению и Worker нужен HTTP-сервер.

GitHub Pages использует существующий workflow `.github/workflows/deploy.yml`. Текущая версия восстановлена из предоставленного архива в ветке `feature/vocal-recovery`. Архив не содержит Git-историю; для переноса создайте ветку в своём репозитории и скопируйте файлы. Публикация не выполнялась.
