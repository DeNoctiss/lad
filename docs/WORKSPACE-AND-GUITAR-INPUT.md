# Обновление рабочих экранов и практика ликов

## Что изменено

Главный принцип: сначала рабочая область и основное действие, затем настройки по запросу. Светлая и тёмная темы сохранены. Подписи не меньше 14 CSS px; основные элементы и поля — 16 px. Библиотека, форматы партий, импорт, экспорт и музыкальные алгоритмы предыдущей версии не мигрируют и не переписываются.

| Раздел | Что мешало | Изменение |
| --- | --- | --- |
| Библиотека | Крупный вступительный блок, постоянно открытые жанры | Компактный заголовок; фильтр жанра раскрывается, поиск и сортировка доступны |
| Боковое меню | Разделы разных задач смешивались | Группы «Библиотека», «Практика», «Справочники»; сокращены декоративные отступы |
| Сольфеджио | Каталог из 14 видов упражнений конкурировал с заданием | Смена упражнения и параметры свернуты в верхней строке; задание занимает основную ширину |
| Сольфеджио: задание | Подсказка занимала место до ответа, остановка звука была далеко | Подсказка раскрывается; остановка рядом с прослушиванием; при загрузке виден статус |
| Гитарная практика | Настройки и пояснения отодвигали гриф | Тональность/подписи/темп, аккомпанемент, пояснения раскрываются отдельно; полный гриф сохранён |
| Прогрессии | Большой каталог и селекторы длительностей отвлекали | Каталог сворачивается; длительности показываются отдельной кнопкой |
| Вокальный тренажёр | Постоянная колонка настроек сужала пианорол | «Подготовить партию» / «Тренироваться»; настройки под рабочей областью; транспорт над нотами |
| Вокальная тренировка | Инструменты редактирования мешали пению | В тренировке скрыты импорт-карточки, рисование, ластик и редактирование сетки; масштаб и микрофон доступны |
| Табулатуры | Контекст выбранной позиции был внизу меню | Текущий такт/струна выше инструментов; «Ещё» переименовано в «Приёмы и параметры» |
| Аккорды / CAGED / справка | Фильтры и длинные вводные блоки конкурировали с материалом | Фильтр тоники и вводные пояснения раскрываются отдельно |
| Песни, избранное, теория, определители | Уже есть подходящие списки/навигация | Сохранены существующие сценарии; общая типографика и переносы улучшены, проверена адаптивность |

Тип, уровень и раздел сольфеджио запоминаются как настройки интерфейса. Открытие прямой ссылки на упражнение имеет приоритет. Звук и микрофон никогда не включаются автоматически.

## Как попробовать гитару

1. Запустите проект: `npm ci`, затем `npm run dev` (в PowerShell при ограничении запуска скриптов — `npm.cmd ci` и `npm.cmd run dev`). Сайт по умолчанию использует порт 5174.
2. Откройте боковое меню → **Гриф и гитара** → **Гитарная практика** → **Лики и движения**.
3. Выберите фразу и тонику. Переключитесь на **Сыграть по шагам**.
4. В «Аудиовход и помощь» выберите устройство. Первый запрос разрешения может быть нужен, чтобы браузер показал названия устройств. При необходимости обновите список после разрешения.
5. Нажмите **Включить проверку**. Используйте чистый сигнал гитары через звуковую карту или микрофон. Для эталона наденьте наушники; вход не выводится обратно в динамики.
6. Играйте указанную ноту. После устойчивого совпадения тренажёр перейдёт дальше и переместит подсказку на грифе.
7. «Послушать ноту» останавливает проверку. После эталона включите её вручную. «Шаг →» и «← Шаг» позволяют разобрать трудное место; это ручная навигация, а не заработанный результат.
8. Для новой попытки нажмите **Начать заново**, затем включите проверку. На последнем шаге ввод выключается автоматически.

### Что именно оценивается

Пока это пошаговое упражнение по высоте **одиночных** нот, без таймера и оценки ритма. Нет общего рейтинга и сохранения «процента мастерства» — ручное перемещение по шагам не должно создавать ложную статистику.

- Октава должна совпадать. E3 и E4 — разные цели.
- Нужен устойчивый сигнал около 150 мс, доверие детектора не ниже 0,85 и отклонение не более 45 центов. Реальная задержка больше этого времени из-за окна анализа и устройства.
- Для повторной одинаковой ноты требуется новый щипок с заметным ростом уровня либо приглушение не менее 80 мс. Один долгий звук не проходит всю цепочку одинаковых нот.
- При слайде, hammer-on и pull-off проверяются начальная и целевая высоты. Это **не доказательство**, что исполнен именно этот приём.
- Бенд проверяется по начальной ноте и высоте на тон выше; release — в обратном порядке, prebend — по поднятой ноте. Эти значения соответствуют текущему учебному каталогу.
- Для вибрато проверяется основная высота, не форма и глубина колебаний.
- На грифе показывается предписанная позиция, а не распознанный палец, лад или струна. Одинаковую высоту на разных струнах надёжно различить этим алгоритмом нельзя.
- Для интерактивных ликов применяется стандартный строй E–A–D–G–B–E. Селекторы строя других вкладок к ликам не относятся.

### Звук и приватность

Сигнал обрабатывается локально в браузере, не записывается в файл и не отправляется на сервер. Ввод автоматически останавливается при уходе из режима, смене фразы/тоники, скрытии вкладки и отключении устройства. Отмена запроса разрешения освобождает даже поток, который браузер вернул позже.

Аудиовход требует HTTPS или localhost. Подключение по обычному HTTP к IP-адресу другого компьютера может быть недоступно.

Рекомендуется монофонический чистый сигнал без перегруза, компрессора, реверберации и задержки. Проверка не является полифоническим распознавателем аккордов. При перегрузке измерение не засчитывается: уменьшите gain на звуковой карте. Слишком слабый сигнал тоже не засчитывается.

## Для разработчика

- `src/lib/guitar/practice.ts` — независимая модель шагов и состояния проверки. Здесь меняются допуск, минимальная устойчивость и правила повторных нот.
- `src/lib/audio/instrumentInput.ts` — жизненный цикл входа, разрешения, список устройств и анализ кадров. Автоматическое усиление, шумоподавление и эхоподавление запрашиваются выключенными.
- `src/lib/vocal/pitch.ts` — общий YIN-детектор. Добавлен необязательный диапазон; значения по умолчанию вокального тренажёра сохранены. Гитарный диапазон — 55–1600 Гц.
- `src/components/guitar/LickPractice.tsx` — экран обратной связи и подключение к устройству.
- `src/components/guitar/GuitarLab.tsx` — переключение «Послушать» / «Сыграть по шагам», выбранная фраза, тоника и интеграция с грифом.
- `src/components/guitar/AnimatedNeck.tsx` — гриф; `practicePitch` показывает текущую целевую высоту при переходах.
- `src/components/ui/Disclosure.tsx` — доступные с клавиатуры раскрываемые настройки на основе native details/summary.
- `src/lib/usePreference.ts` — необязательные настройки интерфейса под ключами `lad-ui-*`. Не трогает `lad-library-v1`.
- `src/styles/studio.css` — общие изменения компоновки под `.workspace-refresh`.
- `src/lib/guitar/practice.test.ts` — модель проверки, повторные ноты, синтетические сигналы, октавы, тишина и перегрузка.
- `e2e/workspaceRefresh.e2e.ts` — адаптивность, работа упражнений, тренировка вокала и реальный WebAudio-конвейер с искусственным MediaStream, отказ/отмена разрешения.

Добавление ликов подробно описано в `docs/ADDING-LICKS.md`; каталог расположен в `src/lib/guitar/model.ts`. Новый лик автоматически получает шаги из его нот и техники. Для новой техники нужно одновременно расширить модель, звуковую огибающую, визуализацию и `practiceSteps`, а не добавлять только подпись.

## Границы этой поставки

Не добавлены: синхронная оценка игры под минус, полифоническое распознавание, распознавание физических пальцев/струн, точная оценка вибрато/бендов, редактор ликов и полная резервная копия аудио. Это отдельные последующие этапы.

Библиотека и результаты сольфеджио продолжают экспортироваться существующими отдельными действиями. Загруженное аудио вокального тренажёра после перезагрузки требуется выбрать снова.

## Проверка

Результаты итоговой проверки см. в `docs/VERIFICATION-WORKSPACE.md`. Проверки с искусственным сигналом не заменяют испытание с реальной гитарой, конкретной звуковой картой и микрофоном пользователя.
