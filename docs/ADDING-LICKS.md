# Как добавить собственный лик

В этой версии лики описываются в исходном файле `src/lib/guitar/model.ts`. Визуального редактора каталога пока нет. Изменения сохраняются в проекте и попадают в сборку, поэтому их видят все пользователи этой сборки.

1. Откройте файл и найдите массив `export const LICKS: Lick[] = [`.
2. Добавьте объект ниже перед закрывающей скобкой этого массива (между объектами нужна запятая).
3. Сохраните файл. При `npm run dev` он появится в списке «Учебная фраза».
4. Перед публикацией выполните `npm run build`. Для сайта загрузите новую сборку привычным способом.

```ts
{
  id: "my-first-slide", // уникальный постоянный идентификатор
  title: "Моя фраза со слайдом",
  goal: "Скользите без повторного щипка, затем завершите на тонике.",
  notes: [
    { string: 2, fret: 5, beats: 2, technique: "slide", target: 7 },
    { string: 1, fret: 5, beats: 1, technique: "pick" },
    { string: 0, fret: 5, beats: 1, technique: "vibrato" },
  ],
},
```

## Струны, лады и время

- `string`: индекс от **0 до 5**, от тонкой к толстой. 0 — первая E4; 1 — B3; 2 — G3; 3 — D3; 4 — A2; 5 — шестая E2.
- `fret`: лад 0–24. 0 — открытая струна. Это позиция пальца, не номер MIDI-ноты.
- `beats`: длительность события в четвертных долях: 0.5 — восьмая, 1 — четверть, 2 — половинная. Допустимы положительные значения; для коротких учебных фраз разумно 0.25–4.
- События идут последовательно. `beats` слайда включает начальную ноту, переход и удержание конечной; добавлять второе событие для окончания этого же слайда не нужно.
- Исходные аппликатуры каталога записаны **для Am, стандартный строй E A D G B E**. Выбор другой тоники сдвигает всю фразу. Для схемы из Bm сначала вычтите два лада или выберите эквивалентную аппликатуру в Am.
- Открытая струна при транспонировании превращается в зажатую ноту. Программа сохраняет струны и относительное расстояние, но не ищет оптимальные новые пальцы.

## Приёмы

| technique | Действие | target |
|---|---|---|
| `pick` | Обычный щипок | Не нужен |
| `slide` | Непрерывный слайд вверх или вниз | Конечный лад той же струны |
| `hammer` | Hammer-on, восходящее легато | Более высокий лад той же струны |
| `pull` | Pull-off, нисходящее легато | Более низкий лад той же струны |
| `bend` | Подтяжка на тон с удержанием | Не нужен |
| `release` | Подтяжка на тон и отпускание | Не нужен |
| `prebend` | Звук уже подтянутой струны, затем отпускание | Не нужен |
| `vibrato` | Вибрато после начала ноты | Не нужен |

Величина бенда сейчас фиксирована: **два полутона**. `target` у бенда не меняет её. Для другого размера подтяжки потребуется расширить модель и общую функцию `expression`; она управляет и звуком, и движением кружка.

В текущей модели нет пауз и одновременных нот внутри лика. Для таких фраз следует расширять модель событий, а не подставлять выдуманный номер струны. Показанные пальцы в боксах — вариант аппликатуры, а не автоматическая расстановка пальцев для каждого лика.

## Проверка своей фразы

- Сначала выберите Am и темп 60. Сверьте лады, длительности и порядок нот.
- Проверьте её в соседней тональности и на краях грифа: все исходные и конечные лады должны оставаться в диапазоне 0–24.
- Для `slide`, `hammer` и `pull` обязательно задавайте `target`; остальные приёмы его не используют.
- При изменениях каталога запускайте `npm test`: тесты транспонирования проверяют все элементы LICKS. Если расширяете число примеров, тест минимального размера каталога не требует изменения.

Настройки грифа хранятся отдельно от библиотеки песен под ключом `lad-guitar-practice-v1`. Изменение TypeScript-файла может вызвать обновление страницы в режиме разработки; выбранная тональность и основные параметры теперь восстанавливаются, звук автоматически не запускается.
