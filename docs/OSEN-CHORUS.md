# Wildways, TRITIA — «Осень»: шаблон припева

Шаблон подготовлен по присланной акапелле `audio [vocals] (1).mp3`, длительность исходного файла около 178,457 секунды. Встроены 58 редактируемых нот фрагмента **0:57,45–1:27,15**. Длина петли — **29,7 секунды**. Сетка — **135 BPM, оценочно**: это разметка для работы, а не установленный официальный темп песни.

## Как открыть

1. Откройте отдельную вкладку **«Вокальный тренажёр»** в основном меню.
2. Нажмите **«Открыть шаблон «Осень»»**. Та же кнопка есть на главной странице. Шаблон добавляется в библиотеку как песня; повторное открытие сохраняет ваши правки.
3. Чтобы услышать акапеллу, загрузите **полный исходный файл** через маленькую кнопку **«Загрузить» в дорожке «Акапелла» слева**. Сохраните имя файла: оно связывает аудио с сохранённым сдвигом.
4. В «Дополнительно» проверьте сдвиг акапеллы **−129,2625 доли**. Это **−57,45 секунды** при 135 BPM: начало проекта совпадает с началом выбранного припева.
5. Нажмите «Вся мелодия», затем воспроизведение. Петля уже включена: от 0 до 66,825 доли.

Верхняя большая кнопка «Акапелла» запускает новое распознавание и заменяет ноты после подтверждения. Для фонового звучания готового шаблона используйте загрузку в левой дорожке.

Если переименовали файл, вручную верните сдвиг −129,2625. Если вырезали только припев, установите сдвиг 0. Нельзя загружать обрезанный припев с сохранённым сдвигом для полной записи.

## Что получилось с высотой

Основные опорные ноты шаблона — D4, E4, F♯4; встречаются G4 и A4. Диапазон шаблона D4–A4 (MIDI 62–69). В полифонических местах, с бэк-вокалом и эффектами, выбор основной линии приближённый. Начала/концы нот также рабочие, их можно поправить в редакторе.

В предыдущем анализе записи были ошибки **в обе стороны**, поэтому автоматически опускать всю распознанную мелодию на 12 полутонов неверно. Например, около 12-й секунды полной записи старое распознавание выбирало F♯5 вместо основной F♯4; около 38-й секунды встречалась обратная ошибка B2 вместо B3. Обновлённый анализ сравнивает несколько возможных высот и учитывает соседние кадры. Сохранённые результаты дополнительно сравнивались с независимым pYIN-анализом; это проверка согласованности, не профессиональная эталонная разметка.

| Нота | MIDI | Частота эталона |
| --- | ---: | ---: |
| A3 | 57 | 220 Гц |
| D4 | 62 | 293,66 Гц |
| E4 | 64 | 329,63 Гц |
| F♯4 | 66 | 369,99 Гц |
| A4 | 69 | 440 Гц |

Кнопки **«На октаву ниже / выше»** переписывают ноты на ±12 полутонов, оставляя аудио и настройку транспонирования прежними. Операция отменяется через Ctrl/Cmd+Z. Это позволяет исправить целиком неверный регистр. Для отдельных ошибок выберите ноту и используйте стрелки вверх/вниз.

Настройка **«Транспонирование»** — другая операция: она меняет звучание эталона и аудио вместе, например для удобной тональности тренировки. В «Дополнительно» есть контрольные звуки A3/220 Гц и A4/440 Гц.

Запись вашего собственного пения не предоставлена, поэтому по акапелле исполнителя нельзя проверить, на какой октаве пели именно вы. Если распознаватель показывает разницу около 1200 центов, сначала сравните с контрольным звуком и проверьте ноты.

## Файлы и ограничения

- `src/lib/vocal/templates/osen-chorus.json` — встроенный проект.
- `docs/examples/osen-chorus.json` — копия для ручного импорта через кнопку JSON.
- `docs/examples/osen-chorus.mid` — MIDI с той же мелодией, 960 PPQ и темпом 135 BPM. MIDI не содержит фонограмму, сдвиг аудио, петлю или настройки тренажёра; для них используйте JSON.
- `src/lib/vocal/osenTemplate.ts` — карточка песни и пояснения.

Это **рабочая транскрипция предоставленной записи**, а не официальная партитура и не обещание точного распознавания всех голосов. Исходный MP3 не входит в архив приложения и не публикуется вместе с ним. После перезагрузки страницы аудио нужно выбрать снова; ноты и параметры сохраняются.
