# Сравнение на акапелле «Осень»

Запись: предоставленный пользователем файл Wildways & TRITIA — «Осень». Аудио не включено в архив.

На припеве 0:57,45–1:27,15 (29,7 с) в предыдущем проверочном запуске:

| Вариант | Событий / нот | Время обработки |
| --- | ---: | ---: |
| Прежний алгоритм | 73 | 2,81 с |
| Исходные полифонические события Basic Pitch | 144 | В составе нового прохода |
| Basic Pitch + одноголосная обработка | 66 | 8,53 с |

Время зависит от устройства и включает создание обоих результатов модели для сравнения. В обычном режиме исходные полифонические события повторно не вычисляются.

Количество нот не является показателем точности. Basic Pitch допускает одновременные события, а редактор одноголосный. Начало нового результата — F♯4 → E4 → D4; у старого алгоритма соответствующие E/D местами оказались на октаву ниже. Это локальный признак улучшения, не доказательство точности всей партии. Новый результат также содержит спорные короткие высокие ноты и пропуски.

Полного независимого эталона нет. Старый автоматически полученный шаблон не используется как эталон. Поэтому процент точности и «улучшение на N%» не заявляются. Для объективной оценки нужна ручная разметка высот, октав, начал и концов; отдельно оцениваются пропуски и лишние события.

Модульные проверки покрывают тишину, настоящий скачок на октаву, краткий ложный обертон, паузы, повторные атаки, смену BPM и непрерывность времени. Браузерный тест с A3/A4 использует известный сигнал. Эти тесты проверяют конкретные свойства, а не точность на всех голосах.

## Проверка полной записи

Полная запись: 178.46 с. Настоящий браузерный инференс завершился без ошибки; выходные ноты находятся в пределах исходной временной шкалы.

- Прежний алгоритм: 444 нот, 8.02 с в тестовом окружении.
- Basic Pitch + обработка: 454 нот, 29.42 с в тестовом окружении.
- Исходный полифонический Basic Pitch: 851 событий.

Полный проход подтверждает работоспособность на длинном файле, а не правильность каждой ноты.

Проверки итоговой версии: production build успешен; 549 модульных тестов, 18 основных браузерных сценариев и 2 проверки production-сборки/диалога пройдены.
