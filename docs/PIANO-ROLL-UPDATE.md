# Пианорол: края нот и музыкальная сетка

## Управление мышью

- Наведите на левый край ноты: появится курсор ↔ и подсветка края. Перетаскивание изменяет начало и длительность, сохраняя конец ноты.
- Правый край изменяет конец и длительность, сохраняя начало.
- Средняя часть переносит ноту по времени и высоте, сохраняя длительность. Курсор ладони меняется при захвате.
- У наведённой или выбранной ноты видны ручки по краям. Для очень коротких нот увеличьте масштаб: зоны краёв занимают не более трети ширины каждая, середина остаётся доступной.
- Контекстная подсказка над сеткой объясняет действие под курсором. Обычный клик только выделяет и прослушивает ноту, не меняя её данные.
- Esc отменяет текущее перетаскивание. Завершённое действие отменяется кнопкой отмены или Ctrl+Z / ⌘+Z. Ctrl+Shift+Z / ⌘+Shift+Z повторяет его.
- Стрелки вверх/вниз меняют высоту на полутон; влево/вправо перемещают по времени; Shift + влево/вправо меняет длительность. Delete удаляет ноту.

Во время воспроизведения или занятия редактирование блокируется. Для изменения нот остановите воспроизведение.

## Что означает шаг сетки

Внутренняя единица времени — четвертная доля. Выбор определяет и видимые вертикальные деления, и привязку при рисовании/перетаскивании:

| Выбор | Делений на четверть | Длительность деления в долях |
| --- | --- | --- |
| 1/4 · четверть | 1 | 1 |
| 1/8 · восьмая | 2 | 0,5 |
| 1/16 · шестнадцатая | 4 | 0,25 |
| 1/8T · триоль | 3 | 1/3 |

Пунктир показывает мелкие деления; сплошные линии обозначают четверти и границы тактов. При сильном отдалении мелкие линии скрываются, чтобы не сливаться. Появляется пояснение; привязка продолжает работать. Приблизьте поле кнопкой «+» или Ctrl / ⌘ + колесо. Подписи тактов при отдалении тоже прореживаются.

Смена сетки сама по себе **не округляет уже записанные ноты**, не меняет MIDI, BPM или аудио. При горизонтальном перетаскивании изменяемая граница привязывается к сетке. При вертикальном переносе время остаётся неизменным. Импортированные короткие ноты не растягиваются при простом выделении или изменении высоты.

Редактор остаётся одноголосным: при наложении редактируемая нота имеет приоритет, пересечённые соседние ноты обрезаются или разделяются. Отмена восстанавливает всё действие, включая соседние ноты.

## Где находится код

- `src/components/vocal/PianoRoll.tsx` — SVG-сетка, курсоры, обработка указателя, подсказки и клавиатура.
- `src/lib/vocal/rollEditing.ts` — независимые расчёты переноса, изменения краёв, геометрии ручек и описание вариантов сетки.
- `src/styles/vocal.css` — светлая/тёмная тема сетки, подсветка краёв и курсоры.
- `src/lib/vocal/rollEditing.test.ts` — границы, триоли, короткие MIDI-ноты и пересечения.
- `e2e/vocalRoll.e2e.ts` — браузерные проверки жестов, отмены, визуальной сетки и сохранения данных.

Запуск: `npm ci`, затем `npm run dev`. На Windows при ограничениях PowerShell используйте `npm.cmd`. Проверка: `npm test`, `npm run build`, браузерные сценарии — `npm run test:e2e` после установки Chromium командой `npx playwright install chromium`.
