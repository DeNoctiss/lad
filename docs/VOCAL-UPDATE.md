## Запуск и перенос

1. Распакуйте папку `lad` в отдельный каталог, чтобы предыдущая рабочая версия осталась у вас.
2. Откройте терминал в этой папке, где лежит `package.json`.
3. Используйте Node.js 22.12 или новее из совместимой LTS-ветки.
4. Выполните `npm ci`, затем `npm run dev`.
5. Откройте `http://localhost:5174`. На Windows при блокировке PowerShell используйте `npm.cmd ci` и `npm.cmd run dev`.

Перед обновлением экспортируйте библиотеку кнопкой «Экспорт». При запуске на том же адресе и в том же браузере используется прежний localStorage. Переезд с localhost на другой домен требует импорта резервной копии. Архив содержит исходники, package-lock и звуковые ресурсы; `node_modules` устанавливается командой выше.

## Что исправлено

- **Файлы с первого выбора.** Скрытие вкладки браузера/диалог выбора файла больше не отменяют импорт. Воспроизведение и микрофон при скрытии страницы по-прежнему останавливаются. Новая загрузка отменяет устаревшую, поздний результат старой задачи не подменяет новый.
- **Замена акапельных нот на MIDI.** Выберите файл, затем MIDI-дорожку и нажмите «Создать вокальную партию». Предупреждение о замене находится прямо в окне выбора. Зависимости от системного `window.confirm` в вокальных импортах больше нет. Сам аудиофайл остаётся в микшере.
- **Распознавание.** Вместо единственного локального YIN-минимума используется несколько кандидатов высоты, вероятностное взвешивание и Viterbi-путь по времени. Вибрато меньше дробит ноты, короткие ошибочные скачки на октаву подавляются. Можно ограничить диапазон голоса и заново распознать уже загруженный файл.
- **Октава.** Есть сдвиг всех нот −12/+12 с отменой, без изменения аудио. Включать автоматический −12 для всех записей нельзя: встречаются и ошибки в противоположную сторону. Высота эталона использует общую формулу MIDI; A4 соответствует 440 Гц. Добавлены частоты и контрольные звуки.
- **Синхронизация.** При смене источника нот скорость сбрасывается на 1×, транспонирование — на 0. Аудиодорожки привязываются к новой сетке BPM, их сдвиг сохраняется в секундах. Загрузка фоновой акапеллы сама не меняет ноты.
- **BPM.** Поле можно очистить и набрать заново. Enter или выход из поля применяет значение; Escape восстанавливает прежнее. Недопустимое значение не записывается. Изменение BPM меняет сетку с сохранением времени нот/петли/аудио. Для ускорения или замедления используйте «Скорость».
- **Масштаб.** Диапазон 1–800%, кнопки +/−, Ctrl/Cmd + колесо и «Вся мелодия». При сдвиге нот на октаву вертикальная прокрутка следует за нотами.
- **Отдельный тренажёр.** В главном меню есть «Вокальный тренажёр», адрес `#vocal`. Можно тренироваться без создания песни. Черновик сохраняется в `library.vocalDraft` и входит в экспорт/импорт всей библиотеки. На узком экране пункт доступен через меню.
- **«Осень».** Готовый рабочий шаблон припева на 58 нот. Инструкция: [OSEN-CHORUS.md](OSEN-CHORUS.md).

## Почему MIDI с 120 BPM не обязательно ошибочный

MIDI описывает время через тики и карту темпа. Экспортёр может выбрать сетку 120 BPM, сохранив верные интервалы в секундах. Само число 120 ещё не означает, что файл ускорен. Импортёр сохраняет время нот с учётом MIDI tempo map. Обновлённое поле BPM перестраивает сетку, сохраняя это время.

Если интервалы уже неверны внутри экспортированного MIDI, изменение одной сетки BPM их не исправит: подберите скорость или исправьте исходный MIDI. Точный MIDI с внешнего конвертера не был приложен; проверялись стандартные SMF-файлы и сохранение их времени, а также ваша реальная акапелла.

## Где менять код

| Файл | Ответственность |
| --- | --- |
| `src/lib/vocal/yin.ts` | Кандидаты частоты и диапазоны голоса |
| `src/lib/vocal/transcribe.ts` | Связь кадров, подавление кратких октавных ошибок, сегментация нот |
| `src/lib/vocal/projectEditing.ts` | Смена сетки BPM, замена мелодии, октавный сдвиг |
| `src/components/vocal/useVocalSession.ts` | Раздельная отмена импорта/воспроизведения, аудио и микрофон |
| `src/components/vocal/VocalTrainer.tsx` | Состояние, импорты, подтверждения и история |
| `src/components/vocal/NumberField.tsx` | Редактируемый черновик числового значения |
| `src/components/vocal/TranscriptionDialog.tsx` | Выбор диапазона и подтверждение распознавания |
| `src/components/vocal/PianoRoll.tsx` | Масштаб, прокрутка, редактирование нот |
| `src/pages/VocalPage.tsx` | Свободная тренировка вне песен |
| `src/lib/model.ts` | Валидация и хранение отдельного черновика |

Старые проекты читаются без миграции. Повреждённый импорт отклоняется до сохранения. Аудиоданные и запись микрофона не отправляются на сервер и не входят в JSON: они живут только в текущем сеансе.
