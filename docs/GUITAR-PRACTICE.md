# Гитарная практика и ответы на пианино

Открыть: боковое меню → Гриф → Гитарная практика.

## Что добавлено

- Пять боксов минорной и мажорной пентатоники. Тоника меняет позиции и подписи. Режим соседних боксов, весь гриф, блюзовая нота, ноты/ступени/смешанные подписи и вариант пальцев.
- 20 авторских учебных ликов. Табулатура, длительности в долях, обозначения приёмов, шаг назад/вперёд, выбор позиции щелчком по табулатуре, темп 40–160 BPM, пауза и цикл.
- Стрелки переходов, непрерывный слайд, H/P, бенд с удержанием, отпусканием и пребенд, вибрато и импульс повторного щипка.
- Один AudioContext задаёт время гитары, пианино и анимации. Высота каждой звучащей ноты меняется независимо. Пауза останавливает источники, продолжение восстанавливает позицию с учётом кривой высоты.
- 20 прогрессий и 12-тактовый блюз: жанры, транспонирование, обращения, септаккорды, пианино и подсветка аккордовых нот. Каталог локальный: API и авторизация не используются.
- Кнопка сохранения текстового разбора лика создаёт запись в группе «Гитарная практика»; её можно редактировать и экспортировать обычными средствами библиотеки.
- В построении интервалов и трезвучий сольфеджио — двухоктавная клавиатура вместо готовых ответов. После проверки видны правильные клавиши. Проверяется точная октава, указанная в задании, и основной вид аккорда.
- На прежнем грифе добавлены ступени и комбинированные подписи. В определителе тональностей процент считается от выбранных уникальных нот, результаты идут по убыванию совпадений: пять, затем до двадцати.

## Как попробовать

1. Выберите Am и первый бокс. Переключите на Bm: форма сдвигается на два лада.
2. Откройте «Лики и движения», затем «Подтянуть и отпустить», темп 60. Нажмите «Играть».
3. Сравните с «Попадите в высоту»: здесь бенд не возвращается перед следующим щипком.
4. Включите аккомпанемент. Исходный оборот — i–iv–V–i. Другие выбираются в «Прогрессиях».
5. Сольфеджио → Построение аккордов: наберите три ноты и нажмите «Проверить».

## Файлы

- `src/lib/guitar/model.ts`: боксы, лики, транспонирование, общая функция кривой высоты.
- `src/lib/guitar/audio.ts`: безопасный разбор локальных звуковых банков без eval, кэш, независимые голоса, синхронное расписание.
- `src/lib/guitar/progressions.ts`: локальные прогрессии, качества аккордов, транспонирование.
- `src/components/guitar/GuitarLab.tsx`: управление практикой.
- `AnimatedNeck.tsx`: гриф и движения; `LickTab.tsx`: табулатура.
- `src/components/solfege/AnswerKeyboard.tsx`: клавиатура ответа.
- `src/lib/solfege/exercises.ts`: цели для клавиатуры; существующие текстовые ответы сохранены для совместимости.

Новый лик: добавьте объект в LICKS. Струны идут от тонкой (индекс 0) до толстой (5). Исходная тональность — Am. `beats` — общая длительность события; для слайда/легато `target` задаёт конечный лад той же струны. Кривая `expression` общая для звука и анимации.

## Источники и границы версии

Источники прогрессий: https://www.hooktheory.com/trends и https://www.musicca.com/chord-player . Это учебная подборка, не статистический топ. Первые три оборота — стартовые примеры Trends; остальные — жанровые примеры Musicca, при необходимости транспонированные. Чужие мелодии и записи ликов не копировались. Ссылки на конкретные песни пока не включены.

Сэмплы уже находились в проекте: `soundfonts/mk/electric_guitar_clean-mp3.js` (Musyng Kite) и `soundfonts/acoustic_grand_piano-mp3.js` (FluidR3). Сведения о лицензиях и источниках добавлены в `public/licenses/guitar-practice-samples.txt`. Не заменять их звуками Hooktheory.

Это учебное сэмплированное воспроизведение, не физическая модель гитары: шум скольжения, отдельные записи legato и изменение тембра натянутой струны не моделируются. Сэмпл естественно затухает; на очень длинном удержании не создаётся искусственный бесконечный сустейн.

Боксы и учебные лики предназначены для стандартного строя. Альтернативные строи остаются в прежних вкладках грифа; стандартные формы к ним автоматически не применяются. Пальцы — возможный вариант, а не единственно верная техника.

Сохранение лика в блокнот пока текстовое: интерактивная кривая бенда не переносится в старый редактор партитуры. В этой версии нет редактирования самих кривых, автоматической оценки гитары микрофоном или поиска удобной новой аппликатуры.

## Запуск

В папке `lad`: `npm ci`, затем `npm run dev`. Сервер использует порт 5174. Windows PowerShell: `npm.cmd ci`, `npm.cmd run dev`. Сборка: `npm run build`; GitHub Pages публикует `dist` существующим workflow. Сначала экспортируйте пользовательскую библиотеку через интерфейс. Установка кода не меняет localStorage; прежние песни и вокальные проекты сохраняются на том же origin.

## Исправление 25.10.2026

Гриф всегда показывает диапазон 0–24, с порожком и маркерами ладов; на узком экране он прокручивается горизонтально без уменьшения текста. Режим «Весь гриф» теперь включает все позиции пентатоники, а не меняет диапазон отображения. Номера пальцев сохраняются и для всех позиций; открытая струна отмечена 0. Голубые добавочные ноты подписаны своей ступенью, если для них нет пальца в базовом боксе.

Основные настройки практики восстанавливаются после переходов и перезагрузки. Вкладки внутри грифа сохраняют своё состояние при переключении. Скрытие страницы или вкладки ставит звук на паузу, но не меняет выбор тональности и фразы. Окончание проигрывания оставляет указатель на последней ноте; повторный запуск начинает фразу заново.

Свои фразы: [пошаговая инструкция и готовый пример](ADDING-LICKS.md). Визуального редактора каталога пока нет.

## Проценты совпадений — обновление 25.10.2026

В определителях тональности и аккордов процент теперь означает долю полного
состава кандидата, которую вы выбрали: четыре ноты из семи — 57%, две из
трёх — 67%. Повторы одной ноты в разных октавах не увеличивают совпадение.
Сортировка идёт по доле совпадения, затем по меньшему числу лишних выбранных
нот, затем по большему числу совпавших нот. Лишние ноты перечислены отдельно.
Галочка точного совпадения требует полного состава без лишних нот. Процент
не означает вероятность определения тональности или аккорда.

В обоих разделах сначала показано пять вариантов. «Показать больше вариантов»
раскрывает до двадцати; изменение выбранных нот снова показывает топ-5.

### Обязательное включение всех выбранных нот

В обоих определителях варианты с хотя бы одной выбранной нотой вне их состава
исключаются полностью. Например, C–D–E–G не показывает C (C–E–G), но может
показывать Cadd9 (C–E–G–D). Недостающие ноты кандидата допустимы и уменьшают
процент: четыре из семи — 57%. При отсутствии вариантов показывается сообщение,
что в текущем каталоге нет аккорда или гаммы с таким набором. Это ограничение
каталога, а не утверждение о невозможности такого созвучия в музыке.
